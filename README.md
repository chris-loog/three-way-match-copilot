# Three-Way Match Copilot

Reads supplier invoices and delivery notes with Azure AI Document Intelligence, matches them against purchase orders and goods receipts in an ERP-style Azure SQL database, auto-approves clean documents, and sends exceptions to a review screen where an LLM explains each mismatch.

Everything here is synthetic. The company, suppliers and documents are fictional.
